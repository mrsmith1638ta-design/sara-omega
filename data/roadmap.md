# SARA-OMEGA ROAD Master Completion Roadmap

Purpose: ROAD is the authoritative roadmap, certification, release-readiness, and live-evidence subsystem for SARA-OMEGA.

Evidence states are strictly limited to PASS, PARTIAL, BLOCKED, UNVERIFIED, and NOT_APPLICABLE. ROAD must never convert PARTIAL, BLOCKED, UNVERIFIED, missing evidence, user assertion, inference, or model confidence into PASS.

The mandatory release sequence is:

BUILD -> TEST -> SECURITY -> ADVERSARIAL -> EPISTEMIC -> GOVERNANCE -> PRIVACY -> PERFORMANCE -> RECOVERY -> MULTI-CLOUD -> ACCEPTANCE -> SIGN -> RELEASE

Production acceptance is PASS only when live Railway evidence reports production_accepted=true. Context.dev remains BLOCKED unless live resolver evidence simultaneously reports commercial_authorization=VERIFIED, monetized_runtime=ALLOWED, and production_authorization=SCOPE_VERIFIED.

For build and certification work ROAD follows: attack -> expose -> harden -> retest -> pass -> advance.
