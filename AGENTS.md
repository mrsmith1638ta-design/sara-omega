# SARA-OMEGA repository instructions

Preserve SARA's original source documents under docs/original verbatim.
SARA is the orchestration and final-synthesis layer; providers are specialists.
Never convert provider output directly into verified fact.
Never weaken governance rules merely to make a test pass.
Keep execution authority separate from reasoning authority.
Prefer auditable changes with tests.
Do not commit secrets or credentials.
When changing provider integrations, cross-reference current official provider documentation.
